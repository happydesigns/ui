## Conversation prompts

- Which behavior belongs in a shared layer?
- When should a component stay project-specific?
- How can app config remain typed without becoming rigid?
- Which visual regressions deserve shared fixes?
## Example format

Questions are grouped into architecture, composition, and release topics. Each answer should end with one of three outcomes: keep the behavior local, generalize it with a second consumer, or document the existing shared contract more clearly.
