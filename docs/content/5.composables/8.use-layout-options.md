---
title: "useLayoutOptions"
description: "Resolve typed defaults and overrides for a layout owned by your app."
---

Nuxt auto-imports `useLayoutOptions` when your app extends `@happydesigns/ui`. Give it a typed defaults object and a function that returns the override layers in order. It returns a computed ref that updates when the layers change.

## Example with a tournament layout

A club can reuse `HArticleLayout` for the article frame and resolve its own back-link label and reports heading in the tournament wrapper.

Declare the options in the app and extend the type of its `app.layouts` config. If the app already has a `layouts` extension, add `tournamentArticle` to that declaration.

```ts [app/types/tournament-options.ts]
export interface TournamentOptions {
  backLabel: string
  reportsTitle: string
}

declare module '@happydesigns/ui/types' {
  interface HAppConfigExtensions {
    layouts?: { tournamentArticle?: Partial<TournamentOptions> }
  }
}
```

```vue [app/layouts/tournament-article.vue]
<script setup lang="ts">
import type { ArticleView } from '@happydesigns/ui/types'
import type { TournamentOptions } from '~/types/tournament-options'

const props = defineProps<{
  article: ArticleView
  tournamentOptions?: Partial<TournamentOptions>
}>()

const defaults: TournamentOptions = {
  backLabel: 'Zurück zur Übersicht',
  reportsTitle: 'Turnierberichte',
}

const appConfig = useAppConfig()
const settings = useLayoutOptions(defaults, () => [
  appConfig.app.layouts?.tournamentArticle,
  props.tournamentOptions,
])
</script>

<template>
  <HArticleLayout :article="article" :back="{ label: settings.backLabel, to: '/turniere' }">
    <slot />
    <section v-if="$slots.reports">
      <h2>{{ settings.reportsTitle }}</h2>
      <slot name="reports" />
    </section>
  </HArticleLayout>
</template>
```

Set a heading for all tournaments in the app config.

```ts [app/app.config.ts]
export default defineAppConfig({
  app: {
    layouts: {
      tournamentArticle: { reportsTitle: 'Berichte zum Turnier' },
    },
  },
})
```

A page can override either setting by passing `:tournament-options="{ backLabel: 'Zurück zur Stadtmeisterschaft' }"` to `<NuxtLayout name="tournament-article">`.

Later layers take precedence. Missing values, `undefined`, and `null` inherit the previous value. Explicit values such as `false` and an empty string apply. Lists replace earlier lists, and plain objects merge field by field. Replacing an object with a scalar clears its earlier settings.
