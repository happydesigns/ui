`@happydesigns/ui` standardizes common content shapes without owning application collections. Projects choose their own names, sources, routes, and additional fields.

Use these pages when you define a collection, wire a list or detail page, or decide whether a field belongs in frontmatter, app config, or project code.

## Schema profiles and patterns

| Profile or pattern | Use it for |
| --- | --- |
| `content` | General page content and custom route content. |
| `article` | Blog posts, updates, guides, and article-like entries. |
| `event` | Dated entries with location and link support. |
| No shared schema | Reusable content fragments embedded in pages or components. |
| `user` | Authors and people referenced from content. |
