---
title: "Use the layer"
description: "Install @happydesigns/ui and extend the Nuxt layer from a project."
---
`@happydesigns/ui` is a Nuxt layer. A project extends it, configures the parts it needs, and keeps project-specific content and branding in the project that owns them.

Use this page when you add the layer to a new project or check whether an existing project still follows the expected setup.

1. [Install the layer](/getting-started/installation) and set up the app's stylesheet.
2. [Choose an article layout](/components/article/portable-article-layouts) if the app supplies its own article data, or [add the Content layer](/getting-started/installation#content-collections) for Nuxt Content collections and Studio.
3. [Configure the app](/configuration/app-config) and [check the setup](/getting-started/project-setup-checklist).
