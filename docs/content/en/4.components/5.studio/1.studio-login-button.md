---
title: "StudioLoginButton"
description: "Expose the configured Nuxt Studio login route to unauthenticated editors."
---
`HStudioLoginButton` renders a fixed login action in the lower-left corner of a production site. It reads the configured Nuxt Studio route, validates an existing Studio session, and stays hidden in development mode or while an editor is authenticated.

Add it once to the project's root app shell. The component is client-only, so consumers do not need to wrap it in `ClientOnly`.

```vue [app/app.vue]
<template>
  <UApp>
    <NuxtPage />
    <HStudioLoginButton aria-label="Open the content editor" />
  </UApp>
</template>
```

The layer registers `nuxt-studio` but keeps it disabled by default, so projects without an editorial backend can build without repository credentials. Enable it explicitly in the project's `nuxt.config.ts` and provide the repository details there:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  studio: {
    repository: {
      provider: 'github',
      owner: 'your-organization',
      repo: 'your-repository',
      branch: 'main',
    },
  },
})
```

Production projects also need their authentication settings as described in the [Nuxt Studio authentication documentation](https://nuxt.studio/auth-providers).
