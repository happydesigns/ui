---
title: "Site header"
description: "Share responsive navigation behavior while keeping the visible brand project-owned."
---
`HSiteHeader` reads the active header links from `app.links.header` and renders the matching desktop and mobile navigation. Its slots keep the logo, actions, search, and mobile calls to action local to the application.

```vue [app/components/AppHeader.vue]
<template>
  <HSiteHeader title="Example website">
    <template #title>
      <Logo />
    </template>

    <template #right>
      <UColorModeButton />
      <UContentSearchButton />
    </template>

    <template #body-after>
      <UButton to="/contact" label="Contact" block />
    </template>
  </HSiteHeader>
</template>
```

Use `items` to override the configured links for one instance. The `navigation` and `mobile-navigation` props customize their respective `UNavigationMenu` without duplicating the responsive shell.

Use the `navigation` or `mobile-navigation` slot when a project needs custom menu markup. The `content` slot is forwarded to `UHeader` for complete control over the mobile overlay.
