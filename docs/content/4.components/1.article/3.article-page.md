---
title: "ArticlePage"
description: "Render one article-like content document by path and collection."
---
`HArticlePage` fetches one document from a collection and renders its body with Nuxt Content. It is available from `@happydesigns/ui/content`. Use the named `article` layout when the route also needs the shared header, breadcrumbs, and adjacent links.

## Usage

::ui-example{:preview='false' name="article-page-basic"}
::

When `path` is not passed, the component resolves the current route path. This is the normal setup for article detail routes where the URL and content path match.

### Explicit path

Pass `path` when the route renders a content document from a different path.

```vue [pages/articles/[slug\\].vue] [pages/articles/[slug].vue]
<script setup lang="ts">
const route = useRoute()
</script>

<template>
  <HArticlePage collection="article" :path="`/articles/${route.params.slug}`" />
</template>
```

### Custom detail layouts

Use the [article layout components](/components/article/portable-article-layouts) when the app owns the data or needs a different renderer or additional sections.
