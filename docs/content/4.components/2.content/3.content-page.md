---
title: "Content page"
description: "Render a consumer-owned Nuxt Content document through the shared content layout."
---
`HContentPage` combines collection lookup, not-found handling, the shared `content` layout, and `ContentRenderer`. The consuming application still owns the route and collection source.

```vue [app/pages/[...slug].vue]
<script setup lang="ts">
definePageMeta({
  validate: isContentPageRoute,
})
</script>

<template>
  <HContentPage collection="page" />
</template>
```

Pass an already loaded document when the route needs project-specific side effects such as a branded social image. The layout reuses that document instead of querying the collection again.

```vue [app/pages/[...slug].vue]
<script setup lang="ts">
definePageMeta({ validate: isContentPageRoute })

const { data: page } = await usePageContent({ collection: 'legal' })
useProjectSocialImage(page)
</script>

<template>
  <HContentPage :page="page" collection="legal" />
</template>
```

Use the default slot for a project-specific renderer while retaining the shared lookup and layout behavior.
